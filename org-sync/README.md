# Org metadata sync

Kanoniczna instrukcja: [synchronizacja metadanych przez wspólny koordynator](../docs/information/org-metadata-sync.md).

Konfiguracja celów: [managed-repositories.json](managed-repositories.json). Wskazane projekty Autogrammar obsługuje centralny harmonogram Semcod; nie wymagają lokalnego ORG_SYNC_PAT. Pozostali członkowie używają prawidłowego koordynatora własnej organizacji i jego uwierzytelniania.
